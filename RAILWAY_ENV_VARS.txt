================================================================================
RAILWAY ENVIRONMENT VARIABLES - COPY TO RAILWAY DASHBOARD
================================================================================

Go to: https://railway.app → Your Project → Variables Tab

Add these environment variables:

# Clerk Authentication (REQUIRED)
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=<your_clerk_publishable_key>
CLERK_SECRET_KEY=<your_clerk_secret_key>
CLERK_WEBHOOK_SECRET=<your_clerk_webhook_secret>

# Firebase (REQUIRED)
NEXT_PUBLIC_FIREBASE_API_KEY=<your_firebase_api_key>
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=<your_firebase_auth_domain>
NEXT_PUBLIC_FIREBASE_PROJECT_ID=<your_firebase_project_id>
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=<your_firebase_storage_bucket>
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=<your_firebase_sender_id>
NEXT_PUBLIC_FIREBASE_APP_ID=<your_firebase_app_id>

# Firebase Admin (REQUIRED)
FIREBASE_PROJECT_ID=<your_firebase_project_id>
FIREBASE_CLIENT_EMAIL=<your_service_account_email>
FIREBASE_PRIVATE_KEY=<your_private_key_with_newlines>

# Application (REQUIRED)
NEXT_PUBLIC_APP_URL=https://ghosthunter-production.up.railway.app
NODE_ENV=production

# GitHub OAuth (Optional - for Code Police feature)
GITHUB_CLIENT_ID=<your_github_client_id>
GITHUB_CLIENT_SECRET=<your_github_client_secret>
GITHUB_WEBHOOK_SECRET=<your_github_webhook_secret>

# AI Services (Optional - for Database Agent)
GOOGLE_API_KEY=<your_google_gemini_api_key>

# Email (Optional - for notifications)
RESEND_API_KEY=<your_resend_api_key>

# Blockchain (Optional - for Equity features)
NEXT_PUBLIC_SEPOLIA_RPC_URL=<your_infura_sepolia_url>
NEXT_PUBLIC_EQUITY_TOKEN_ADDRESS=<your_token_contract_address>
SEPOLIA_PRIVATE_KEY=<your_wallet_private_key>

================================================================================
IMPORTANT NOTES:
================================================================================

1. Get Clerk keys from: https://dashboard.clerk.com/last-active?path=api-keys
   - Use pk_live_* and sk_live_* for production

2. Firebase keys from: https://console.firebase.google.com
   - Project Settings → General (for public keys)
   - Project Settings → Service Accounts (for admin keys)

3. For FIREBASE_PRIVATE_KEY:
   - Copy the entire key including "-----BEGIN PRIVATE KEY-----" and "-----END PRIVATE KEY-----"
   - Keep the \n characters for line breaks

4. After setting variables in Railway:
   - Go to Clerk Dashboard → Add domain: https://ghosthunter-production.up.railway.app
   - Go to Firebase Console → Add domain to authorized domains
   - Update GitHub OAuth callback URL (if using)

================================================================================
DEPLOYMENT READY!
================================================================================

Once all variables are set, Railway will automatically deploy your app.
Monitor: https://railway.app → Your Project → Deployments
