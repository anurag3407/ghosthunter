================================================================================
GITHUB WEBHOOK MANUAL SETUP - CODE POLICE
================================================================================

PROBLEM: Your webhook is pointing to localhost instead of production URL.

SOLUTION: Manually update the webhook in GitHub to point to Railway.

================================================================================
STEP 1: Go to Your GitHub Repository
================================================================================

1. Open your repository on GitHub
2. Click "Settings" (top navigation)
3. Click "Webhooks" (left sidebar)

================================================================================
STEP 2: Check Existing Webhook
================================================================================

You should see a webhook with URL like:
❌ http://localhost:3000/api/webhooks/github (WRONG - won't work)

or

✅ https://ghosthunter-production.up.railway.app/api/webhooks/github (CORRECT)

================================================================================
STEP 3A: If Webhook Exists with Wrong URL - UPDATE IT
================================================================================

1. Click on the webhook
2. Change the "Payload URL" to:
   https://ghosthunter-production.up.railway.app/api/webhooks/github

3. Keep these settings:
   - Content type: application/json
   - SSL verification: Enable SSL verification (recommended)
   - Events: Just the push event, Pull requests (or "Let me select individual events")
   - Active: ✓ (checked)

4. Click "Update webhook" at the bottom

================================================================================
STEP 3B: If No Webhook Exists - CREATE NEW ONE
================================================================================

1. Click "Add webhook" button
2. Fill in:
   
   Payload URL:
   https://ghosthunter-production.up.railway.app/api/webhooks/github
   
   Content type:
   application/json
   
   Secret:
   (Leave empty for now - we'll add it after reconnecting in the app)
   
   Which events:
   ✓ Just the push event
   ✓ Pull requests
   
   Active:
   ✓ (checked)

3. Click "Add webhook"

================================================================================
STEP 4: Reconnect Repository in GhostFounder (IMPORTANT)
================================================================================

To get the correct webhook secret:

1. Go to: https://ghosthunter-production.up.railway.app/dashboard/code-police
2. Find your connected repository
3. Click "Disconnect" or delete it
4. Click "Connect New Repository"
5. Select the same repository again

This will:
- Create a new webhook secret
- Update the webhook with the correct URL
- Ensure everything is properly configured

================================================================================
STEP 5: Verify Webhook is Working
================================================================================

After reconnecting:

1. Go back to GitHub → Your Repo → Settings → Webhooks
2. Click on the webhook
3. Scroll down to "Recent Deliveries"
4. You should see a green checkmark on the latest delivery
5. Click on it to see:
   - Request: What GitHub sent
   - Response: Should show 200 OK

================================================================================
STEP 6: Test with a Push
================================================================================

1. Make a small change to your code (add a comment with a typo or something)
2. Commit and push:
   git add .
   git commit -m "Test code police webhook"
   git push origin main

3. Within 5-10 seconds, check:
   - GitHub webhook Recent Deliveries (should show new delivery with ✓)
   - Railway logs (should show [GitHub Webhook] messages)
   - Your app dashboard (should show new analysis run)

================================================================================
TROUBLESHOOTING
================================================================================

Q: Webhook shows red X in GitHub?
A: Click on the delivery, check the error. Common issues:
   - 404: Project not found (reconnect repository)
   - 500: Server error (check Railway logs)
   - Timeout: Railway app might be sleeping (try again)

Q: Still no response after updating?
A: 1. Check Railway logs for errors
   2. Verify environment variables are set in Railway
   3. Make sure you're pushing to the correct branch (main/master)

Q: How do I find my webhook secret?
A: You don't need it manually. Reconnecting the repository in the app will
   automatically create a new secret and configure everything.

================================================================================

Once webhook is set up correctly, every push to your repository will:
1. Trigger the webhook
2. Send event to your Railway app
3. Analyze the code for issues
4. Show results in your dashboard
5. Optionally send email notification

================================================================================
NEW FEATURE: DISCONNECT REPOSITORY
================================================================================

You can now disconnect repositories directly from the Code Police dashboard!

HOW TO DISCONNECT:
1. Go to: https://ghosthunter-production.up.railway.app/dashboard/code-police
2. Find the repository you want to disconnect
3. Click the trash icon (🗑️) on the right side of the project card
4. Click "Yes" to confirm

This will:
✓ Delete the webhook from GitHub automatically
✓ Remove the project from your dashboard
✓ Delete all analysis runs for that project
✓ Clean up all Code Police tracking

RECOMMENDED WORKFLOW FOR FIXING WEBHOOK ISSUES:
1. Disconnect the repository (using trash icon)
2. Reconnect it from production URL
3. This ensures webhook points to Railway, not localhost
